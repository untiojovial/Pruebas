# T4 notes (Epistemology II: al-Radd 'ala al-Mantiqiyyin)

**Searched (Radd, Shamela text):** الحد لا يفيد / تصور المحدود / الحد التام / لفظية / تعريف الماهية; قياس التمثيل / يفيد اليقين / يزعمون / الظن; العلم الضروري / النظري / البديهي / الحسيات / الحدس / الفطرة; الحس والعقل / طرق العلم / الخبر الصادق; الآيات / صدق الأنبياء / المعجزات / المتواتر. Also checked DarTacarud and Majmu' al-Fatawa vol. 9 for the preface.

**Text versions.** The Shamela text (0007626, used) contains the preface but ends mid-sentence (Ibn Arabi / isra section), so it is incomplete. The JK000371 version is complete (ends with the closing formula) but lacks the preface (T4-E01). Printed page numbers agree between the two for the passages checked (E03, E04, E06, E07, E08, E12, E15, E16). The wording differs in spacing and some words, so the Arabic follows the Shamela text. Check page images before quoting.

**Corrections to the brief.** The brief's wording 'المنطق لا يحتاج إليه الذكي' is not in the text; the text reads 'المنطق اليوناني'. The phrase 'لا يحتاج اليه الذكي' in DarTacarud occurs only in an OpenITI biographical blurb, not in Ibn Taymiyya's text.

**Not found.** 'Naqd al-mantiq' is not a separate work in the TSV. The Majmu' index lists 'نقض المنطق' at vol. 4 pp. 1-190, but that title has no body hit. 'نصيحة أهل الإيمان في الرد على منطق اليونان' is at vol. 9 pp. 82-254 (the preface is at 9:81).
