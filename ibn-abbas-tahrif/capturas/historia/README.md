# Historia: capturas de las fuentes, siglo a siglo

Una tarjeta por fuente de la tabla «Siglo a siglo» (pestaña Historia), en el mismo orden cronológico. Cada una tiene la página original con el pasaje subrayado (`Hxx_ar.png`; en H24 y H24b, el original en inglés) y la traducción al español (`Hxx_es.png`).

Colores: amarillo = pasaje citado · naranja = frase clave · azul = matiz o lo que juega en contra. Las marcadas «fuente secundaria» (H10s, H13b, H14, H19b) no son el texto del autor, sino de quien lo cita.

Todo junto en un PDF: [`historia_capturas.pdf`](historia_capturas.pdf).
