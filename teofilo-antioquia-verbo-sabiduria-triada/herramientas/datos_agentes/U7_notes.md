# U7 notes: page scans and Greek text (Ad Autolycum)

## Searched and found
- ANF vol. 2 (CCEL PDF, 1368 pp., text layer): all six key chapters located and checked by pdftotext. PDF pages 199 (1.3), 203 (1.7), 215 (2.4), 225 (2.10), 233 (2.15, with fn. 64), 236 (2.18), 240 (2.22).
- Dods, ANC vol. 3 1867 (archive.org, 503 pp., text layer): PDF pages 69, 78, 86, 93, 95, 99 for the same passages. Printed pages read from running heads.
- Otto, Corpus Apologetarum 8 (Jena 1861, Mauke): archive.org reprint. Text layer is missing (image-only, 1 text page). Only the OCR Latin index was usable.
- Migne PG 6: archive.org PDF (59.9 MB, 646 pp.). No text layer and no Theophilus in the djvu OCR, so no Theophilus page was located.

- Humphry 1852: no archive.org item found.
